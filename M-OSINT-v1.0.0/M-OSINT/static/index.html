RESMİ HIBP API

Have I Been Pwned · E-posta ihlalleri

#50 aracı, HIBP’nin resmi e-posta sorgusunu kullanır. Gerçek adresler için HIBP abonelik anahtarı gerekir. Anahtar yalnızca sunucu belleğinde tutulur; yeniden başlatınca silinir. IP sorgusu anahtarsız kalır.

Her sorguda açık ağ onayı alınır: tam e-posta adresi HIBP’ye gönderilir. E-posta ve sonuçlar oturum vakasına eklenir; anahtar vaka/rapora dahil edilmez. Hassas, emekli ve doğrulanmamış ihlaller kapsam dışıdır. Kota hataları “ihlal yok” sayılmaz.

RESMİ OATHNET API

OathNet · E-posta ihlal özeti

#111 aracı için OathNet API anahtarı ve uygun plan/kota gerekir. Anahtar yalnızca sunucu belleğinde saklanır. HIBP ve IPinfo ayarları bağımsız kalır.

Her sorguda tam e-posta OathNet’e gönderilir; ağ onayı gerekir. Yalnızca ilk sayfanın kaynak adları ve sayıları gösterilir. Ham satırlar, parolalar, hash ve tokenlar sonuçlara, vakaya veya rapora aktarılmaz.
